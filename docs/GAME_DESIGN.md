# 숲속 원정대 — 장기 게임 설계

> 데모(`dist/forest_expedition.html`)를 넘어 장기 운영 게임으로 가기 위한 설계 문서.
> 구현 현황은 맨 아래 [구현 현황](#구현-현황) 참고.

## 1. 게임의 방향

**한 줄 요약: 높은 난이도를 새로운 빌드로 뚫어 나가는 실시간 3인 파티 전략 RPG.**
방치형은 하지 않는다. 오래 하는 이유는 "더 센 숫자"가 아니라 "아직 못 깬 기믹을 새 빌드로 깨는 것"이다.

### 1-1. 자물쇠와 열쇠 (가챠 운영 원칙)
| 원칙 | 내용 |
|---|---|
| 콘텐츠 = 자물쇠 | 새 시즌·보스는 새 기믹을 낸다 (실드 회복, 분신, 반사막, 시간차 폭발, 매혹 등) |
| 캐릭터 = 열쇠 | 새 캐릭터는 새 해법(동사)을 가져온다 (실드 파괴, 끌어오기, 정화, 반사, 시간 정지, 소환 등) |
| 열쇠는 여러 개 | 같은 자물쇠를 기존 캐릭터 조합으로도 풀 수 있어야 한다. "신캐 없으면 못 깸"은 금지, "신캐로 새 공략법이 열림"은 허용 |
| 스탯 예산 고정 | 신캐의 스탯 총량은 기존 캐릭터와 같다. 차이는 기능으로만 낸다 (파워 인플레 방지) |
| 기믹 무시 금지 | "그로기 무시", "약점 무시" 같은 효과는 넣지 않는다 (스타레일 파워 크립 사례) |
| 리워크 | 오래된 캐릭터는 주기적으로 각성(새 태그 추가)해 다시 쓸 이유를 만든다 |

### 1-2. 캐릭터 = 직업 × 기믹 태그
| 축 | 예시 |
|---|---|
| 직업(역할) | 탱커, 근딜, 원딜, 매지션, 서포터 (+ 추후 소환사, 방해꾼) |
| 기믹 태그 | [끊기] [그로기 특화] [정화] [위치 조작] [실드 파괴] [소환] [반사] … |
| 작전 성향 | 돌격형 / 대형형 / 후퇴형 (작전별 보너스가 다름) |

같은 탱커라도 "끊기 탱커"와 "끌어오기 탱커"는 다른 빌드가 된다. 장비는 직업 공용이라 장비 파밍의 가치가 유지된다.

### 1-3. 수익 구조
| 판매 | 판매하지 않음 |
|---|---|
| 캐릭터 가챠 (천장 있음) | **장비** — 장비는 플레이로 파밍한다. 빌드 연구의 재미를 지킨다 |
| **캐릭터 스킨 + 무기 스킨** | 강화 재료 직판 (주간 한정 패키지 정도만 검토) |
| 시즌 패스 | 스탯을 직접 올리는 상품 |

- **캐릭터를 사는 이유 = 그 캐릭터만의 필살기 풀.** 장비가 ①②를 정하므로 캐릭터의 정체성은 고유 필살기들에 있다 (아래 2-2).
- 중복 획득(돌파)은 필살기를 **강화**하고 **변주**를 연다. 과금 차이 = "더 셈"이 아니라 "선택지가 많음". 예: "3돌파하면 두 번째 필살기의 변주가 열리는데 그게 매력적이다"가 뽑을 이유가 된다.
- 무기 스킨은 외형만 바꾸고, 등급·강화 발광 효과는 스킨 위에도 그대로 보인다.

## 2. 스킬 구조 (확정)

캐릭터당 버튼 3개는 늘리지 않는다. 깊이는 "무엇을 들고 가느냐"로 만든다.

| 버튼 | 결정 요소 | 규칙 |
|---|---|---|
| ① | **갑옷** | 갑옷 종류마다 ① 스킬이 고정. 장비 등급은 같은 스킬의 랭크를 올림 |
| ② | **무기** | 무기 종류마다 ② 스킬이 고정. 직업마다 무기 계열 6종(딜/공략/생존 축) |
| ③ | **캐릭터 고유 필살기 풀** | 캐릭터마다 여러 개(다키스트 던전처럼 많이 배우고 1개 장착). 레벨 10마다 1개 해금, 최대 레벨/10개 (70레벨 = 7개) |
| (패시브) | **갑옷 랜덤 패시브** | 고유 이름 패시브가 랜덤으로 붙고, 패시브 등급은 장비 등급 이하에서 랜덤 |
| (강화) | **소울 메달** | 직업 특성 스탯 + ①(갑옷)·② (무기) 스킬 위력 강화. 메달의 최종 역할은 보류 (8장) |

- 교체는 거점(마을)과 원정 중 캠프에서만. 전투 중에는 작전·자동 전략만 바꾼다.

**구현된 ①② 스킬 풀 (직업마다 갑옷 3 · 무기 3, 1번 계열 = 장비 없을 때의 기본 스킬)** — `src/js/01d_gear_skills.js`. 장비 등급 = 스킬 랭크(등급 한 단계마다 위력·회복 +5%). 바꿔 낀 스킬은 자동 전략도 그 스킬의 기본 조건을 따른다.

| 직업 | ① 갑옷 (1 / 2 / 3) | ② 무기 (1 / 2 / 3) | 남는 그로기 역할 |
|---|---|---|---|
| 탱커 | 도발 / 맹세의 외침(도발+파티 보호막) / 가시 반격(도발+평타 반사) | 방패 강타 / 돌진 베기(짧은 기절·강타) / 대지 강타(범위 기절) | ② 기절 (끊기 칸 전부) |
| 근딜 | 급소 베기 / 발목 베기(둔화·짧은 쿨) / 피의 일격(HP 소모·깊은 출혈) | 회전 베기 / 파쇄 일격(그로기 적 1.6배) / 그림자 연격(3연타+취약) | ① 끊기 ●● |
| 원딜 | 관통 사격 / 견제 사격(둔화·짧은 쿨) / 표식 사격(8초 취약) | 화살비 / 연사(4연사) / 저격(1초 조준 후 강타) | ① 끊기 ●● |
| 매지션 | 별빛 탄 / 화염 파동(작은 범위) / 마나 보호막(아군 보호막) | 유성우 / 번개 사슬(시전 중인 적부터 3연쇄) / 빙결 고리(넓은 범위 둔화) | ② 범위 끊기 ● |
| 서포터 | 치유 / 수호의 기도(보호막) / 재생의 축복(재생) — 셋 다 공명 | 광역 치유 / 빛의 심판(공격+취약) / 정화의 빛(파티 회복+해제) | ① 공명 |

**캐릭터 레벨 (구현됨)**: 최대 70. 필살기는 레벨로 배운다 — A Lv1 · B Lv10 · C Lv20 · 변주 A2/B2/C2 Lv30/40/50(돌파도 필요) · Lv60·70 필살기 숙련 +5%씩. 경험치는 전투 승리마다 출전한 캐릭터 전원(쓰러진 캐릭터 절반), 일반 12 · 정예 30 · 보스 80 × (1 + 0.6 × 난이도 단계). 다음 레벨 필요 경험치 = 20 + 10 × (Lv−1)^1.3.
- 어떤 장비 조합이든 그로기를 깎는 수단이 최소 1개 남도록 스킬 풀을 짠다.

### 2-1. 갑옷 패시브
- **이름은 고정, 등급은 배율.** 같은 패시브는 등급마다 수치만 다르다 (UC 1.0 → C 1.15 → R 1.3 → SR 1.5 → SSR 1.75 → UR 2.0 → L 2.3 → E 2.6).
- 등급이 오를수록 성격이 달라진다: UC~R 수치형 / SR~SSR 조건부 발동형 / UR 이상 트레이드오프·키스톤형.
- 같은 이름 패시브가 겹치면 가장 높은 등급 하나만 적용. 파티 대상 패시브는 파티에서 1개만 적용.
- 관리 수단: 재련(종류 재굴림), 연마(등급 재굴림, 장비 등급 이하), 도감(획득 기록), 잠금.

### 2-2. 캐릭터 필살기와 중복 돌파 (가챠의 핵심)
- 캐릭터마다 고유 필살기 여러 개. 레벨로 해금하고 전투 전에 1개를 고른다.
- **돌파(중복 획득)** 단계마다 필살기가 강화되고, 정해진 단계에서 **변주**가 열린다. 변주는 강화된 별도 선택지라 원본과 바꿔 낄 수 있다.
  - 예: 1돌파 = 첫 필살기 위력 강화 / 2돌파 = 첫 필살기 변주 해금 / 3돌파 = 두 번째 필살기 변주 해금 / … 
- 변주는 수치 변경이 아니라 **동작이 바뀌거나 새 기능이 붙는 것**이어야 한다. 돌파하지 않아도 원본 필살기로 콘텐츠를 깰 수 있어야 한다 (변주 = 다른 공략법, 필수 아님).

| 변형 종류 | 예시 |
|---|---|
| 동작 변화 | 별비 「화살비」 → 「회오리 화살비」: 지정 지점이 아니라 별비 주위를 돌며 3초간 쏟아짐 (근접 방어형) |
| 기능 추가 | 토비 「철벽」 → 「반격 철벽」: 철벽 중 받은 피해의 일부를 그로기 피해로 되돌림 |
| 조건 전환 | 솔담 「대마법」 → 「지연 대마법」: 3초 뒤 발동, 그 순간 무방비인 적에게 3배 |
| 대상 전환 | 보리 「생명의 나무」 → 「이식」: 파티 대신 한 명에게 집중, 그 아군의 다음 필살기 게이지 +50% |
| **잭팟 변주** (높은 돌파 단계) | 단비 「난도질」 → 「천 갈래 칼날」: 6연타가 주변 모든 적으로 튀며, 무방비 적 처치 시 게이지 50% 반환 |

- 잭팟급 변주(높은 돌파 단계)는 무방비 6초 안에 고점을 찍게 해주는 효과가 중심. 단, 무방비 시간 연장·그로기 무시는 금지.
- 무방비 중 피해 증폭은 곱이 아니라 합, 상한 있음 (기본 +50% 위에 최대 +40%).

## 3. 장비 강화

### 3-1. 원칙
강화하면 할수록 **더 높은 난이도의 콘텐츠에 도전**할 수 있게 한다 (데미지 놀이가 아니라 도달 높이).
- 난이도 단계(견습 → 태초)와 심연 던전 층수가 강화의 목표가 된다.
- 장비 파괴 없음 (모바일 정서상 고등급 장비 손실은 좌절이 크다).

### 3-2. 강화 수치 (1차 안)
| 강화 | 성공 확률 | 비고 |
|---|---|---|
| +1 ~ +2 | 100% | |
| +3 / +4 / +5 | 95 / 90 / 85% | **+5: 외형 1단계** |
| +6 / +7 / +8 | 75 / 65 / 55% | |
| +9 / +10 | 45 / 35% | **+10: 외형 2단계** |
| +11 / +12 / +13 | 25 / 18 / 12% | |
| +14 / +15 | 8 / 5% | **+15: 외형 3단계** |

- **실패 보정 (로스트아크식):** 실패할 때마다 이번 단계 확률이 기본 확률의 10%씩 올라가고(최대 2배), **장인의 기운**이 (현재 확률 × 0.465)만큼 쌓인다. 기운 100%면 다음 강화는 확정 성공. 단계가 오르면 보정과 기운은 초기화.
- 실패해도 단계가 내려가지 않는다. 대신 재료는 소모된다.
- 강화 한도는 장비 등급에 묶인다: UC +5, C +7, R +9, SR +11, SSR +13, UR 이상 +15.
- 강화 1단계마다 주 스탯 +6% (+15 = +90%). 추가 옵션·패시브는 강화로 오르지 않는다 (빌드는 옵션·패시브로, 도달 높이는 강화로).
- 재료: 강화석(전투 보상) + 골드. 단계가 오를수록 증가.

### 3-3. 외형 (구상만 — 캐릭터 에셋과 무기 장착 방식이 정해진 뒤 구현)
| 요소 | 규칙 |
|---|---|
| 무기 발광 (등급) | 등급이 높을수록 자주·강하게 번쩍인다. UC·C 없음 → R 느린 파랑 → SR 초록 → SSR 보라 → UR 주황 → L 금색 → E 붉은 금색 상시 번쩍임 |
| 무기 발광 (강화) | 강화 단계가 발광의 세기를 키운다. +10부터 불꽃 입자, +15는 잔상까지 |
| 갑옷 외형 (강화) | +5 금색 장식, +10 빛나는 문양, +15 오라와 떠다니는 빛 입자 |
| 스킨 | 스킨 위에도 등급·강화 효과가 겹쳐 보인다 |

구현 메모 (시험 구현 후 제거, 코드는 커밋 `45e9e81`의 `09b_inventory.js`에 남아 있음):
- 스프라이트마다 무기 위치를 선분(손잡이→끝)으로 정의하고, 선분 위 5점에 'lighter' 합성 원형 그라데이션을 그린다.
- 등급표 = 번쩍임 주기·색 (R 3.2초 … E 0.7초 + 상시 빛). 세기 = 0.45 + 강화/15 × 0.75. +10 이상은 무기를 따라 올라가는 입자.
- 갑옷 오라 = 캐릭터 뒤 타원 그라데이션 + 발밑 고리, +15는 떠다니는 빛 입자.
- 실제 원화가 정해지면 무기 끝 좌표를 원화 기준으로 다시 잡고, 파티클은 이펙트 에셋으로 교체.

## 4. 엔드게임 (방치형 없이 오래 하게)

| 콘텐츠 | 방식 | 오래 하는 이유 |
|---|---|---|
| **심연 던전** (상시) | 무한히 이어지는 층. 아래 4장 | 소모전과 교대 판단, 계속 바뀌는 층 성격 |
| **주간 보스 토벌** | 매주 보스 1종과 기믹 조합이 바뀜. 클리어 시간·계약 점수 랭킹 | 매주 새 공략 연구 |
| **고목의 탑** (시즌 등반) | 시즌마다 리셋되는 고난도 층. 상층은 파티 2~3개 필요, 한 캐릭터는 한 파티에만 | 캐릭터 폭 = 실력, 최상층은 소수만 |
| **원정 일지** (스토리) | 챕터마다 새 자물쇠 기믹을 처음 가르치는 튜토리얼 | 신캐·신기믹 소개 |
| 난이도 계약 | 원정에 조건을 붙여 점수를 올림 (하데스 열기 방식). 예: 차지 범위 +30%, 그로기 회복 2배, 회복약 금지 | 조건 조합마다 다른 빌드 |

PvP는 하지 않는다 (실시간 3인 밸런스·네트워크 비용, 기믹 공략 정체성과 맞지 않음). 대신 **같은 시드의 주간 도전 랭킹**으로 경쟁 욕구를 채운다.

## 5. 심연 던전: 소모전과 교대

층이 끝없이 이어지고, 체력과 사망이 이어지는 **소모전**이다. 핵심 재미는 "다음 층의 성격을 보고 누구를 내보낼지" 고르는 판단.

### 5-1. 규칙
- 원정 시작 시 **예비대**를 꾸린다: 출전 3명 + 대기 최대 5명.
- 체력은 층 사이에 회복되지 않는다. 사망한 캐릭터는 이번 심연 원정에서 **은퇴**(다음 원정에 복귀).
- 대기 중인 캐릭터는 층마다 최대 HP의 15% 회복 (쉬는 캐릭터를 돌리는 이유).
- 층마다 **성격 태그**가 미리 보인다: 예) [차지 다수] [졸개 물량] [회복 저하] [원거리 강화] [어둠: 시야 제한] [보스 층].

### 5-2. 교대 규칙 (층 사이)
| 다음 층 종류 | 교대 가능 인원 |
|---|---|
| 일반 층 | 1명 |
| 정예 층 직후 | 2명 |
| 캠프 층 (5층마다) | 전원 + 식량으로 회복 |
| 위기 층 (랜덤) | 교대 불가, 대신 보상 2배 |

- 이번 층 성격에 맞는 캐릭터를 넣고, 지친 캐릭터를 쉬게 하는 판단이 전략의 중심이 된다.
- 교대 인원 제한 때문에 "만능 3명"보다 "상황별 열쇠를 가진 넓은 로스터"가 유리하다 → 캐릭터 수집 동기와 연결.
- 기록: 도달 층수 + 남은 인원 + 계약 점수로 시즌 랭킹.

## 6. 속성 (나중에 구현, 데이터 자리는 지금 만든다)

**결론: 구현은 엔드게임 단계에서, 데이터 칸은 지금 미리 만든다.** 스킬과 적이 많아진 뒤에 속성을 붙이면 전부 다시 손봐야 하기 때문이다.

- 속성 5종 안: 불 · 물 · 바람 · 대지 · 빛/어둠.
- **약점은 피해량이 아니라 그로기 게이지를 더 크게 깎는다** (스타레일식). 속성이 딜찍누 수단이 아니라 기믹 공략 수단이 되게 한다.
- 요일 던전: 요일마다 속성이 바뀌는 던전에서 그 속성의 보석·강화 재료를 얻는다.
- 신캐의 속성이 새 자물쇠(속성 보호막 보스 등)의 열쇠가 된다.

## 7-2. 캐릭터 15명 (직업 5 × 3) — 데모 구현됨

캐릭터의 정체성 = **고유 필살기 3종 + 변주 3종**. ①② 스킬은 직업 기본(추후 장비가 결정). 외형은 기본 5종의 색·체형·얼굴만 바꾼 임시 외형.
참고: LoL 챔피언의 역할 분화(처형·지연 폭발·불사·보호막), 모바일 수집형(에픽세븐·블루 아카이브·명일방주)의 "한 직업 안에서 역할 세분화".

| 직업 | 캐릭터 | 개성 | 필살기 A / B / C (변주) | 참고한 원형 |
|---|---|---|---|---|
| 탱커 | 토비 (시작) | 순수 방어 | 철벽 / 대지 방벽 / 고목의 수호 | 타릭·브라움식 보호 |
| 탱커 | 레온 | 성기사: 방어 + 회복 | 신성한 방패 / 심판의 망치 / 성역 | 레오나·판테온 |
| 탱커 | 고르 | 망자 기사: 불사 + 약화·중독 + 흡혈 | 불사의 맹세 / 부식의 외침 / 망자의 행진 | 문도·요릭·사이온 |
| 근딜 | 단비 (시작) | 출혈 누적 | 난도질 / 회오리 칼날 / 결전의 일격 | 다리우스 출혈 |
| 근딜 | 카이 | 암살자: 처형 + 회피 | 그림자 일격 / 연막 / 사신의 춤 | 파이크·카타리나 |
| 근딜 | 브란 | 파쇄 투사: 그로기 특화 | 대지 가르기 / 분쇄 연타 / 거인 사냥 | 세트·사이온 |
| 원딜 | 별비 (시작) | 안정형 명사수 | 집중 사격 / 화살 폭풍 / 관통 일제 사격 | 애쉬 |
| 원딜 | 하람 | 저격수: 긴 시전 극딜 | 별똥 저격 / 표식 사냥 / 일격필살 | 제라스·징크스 궁, 블루 아카이브 저격 |
| 원딜 | 미르 | 독침: 중독·약화, 독 폭발 | 독안개 / 마비 화살 / 맹독 폭발 | 티모·트위치·칼리스타 |
| 매지션 | 솔담 (시작) | 화염 광역 | 대마법 / 유성 낙하 / 화염 정령 | 브랜드 |
| 매지션 | 서리 | 빙결 제어 | 얼음 감옥 / 눈보라 / 절대영도 | 애니비아·리산드라 |
| 매지션 | 녹스 | 저주·지연 폭발 | 저주 / 영혼 착취 / 파멸의 낙인 | 질리언 폭탄·카서스 진혼곡 |
| 서포터 | 보리 (시작) | 광역 회복 + 부활 | 생명의 나무 / 꽃비 / 부활의 씨앗 | 소라카 |
| 서포터 | 루미 | 음유시인: 버프·쿨 가속 | 용기의 노래 / 서두름의 가락 / 결전의 찬가 | 소나·유미 |
| 서포터 | 세라 | 단일 회복 + 보호막 + 희생 | 기적 / 빛의 보호막 / 희생 | 잔나·킨드레드 궁 |

- **돌파 (0~5):** 1돌 A 위력 +20% · 2돌 A 변주 · 3돌 B 변주 · 4돌 B·C 위력 +15% · 5돌 C 변주. 변주는 원본과 바꿔 낄 수 있는 별도 선택지.
- 필살기 해금은 원래 "레벨 10마다 1개"이지만 캐릭터 레벨이 아직 없어 데모에서는 A·B·C 모두 처음부터 사용 가능.
- 필살기 효과 요소: 시전 시간(이동 불가), 처형, 그로기 배율, 추가 그로기, 흡혈, 피해→파티 회복, 보호막, 해제, 부활, 쿨타임 감소, 게이지 지급, 자기 HP 소모, 연속 처형, 독 폭발. 새 캐릭터는 이 요소 조합으로 데이터만 추가하면 된다.

### 소환 (데모 규칙)
- 소환권으로 1회 / 5회. 15명 균등 확률. 처음 보유 = 기본 5명.
- 소환권: 첫 실행 5장, **보스 격파 시 5장 확정** (데모용). 정식 버전은 천장·확률 고지·등급 차등 필요.
- 최대 돌파 이후 중복 → 강화석 20개.

## 7-3. 카오스 제로 나이트메어와 비교해서 가져올 아이디어

둘 다 "스테이지를 깨며 빌드를 완성해 고점을 찍는" 구조다. CZN은 덱(카드)이 곧 스킬이고 원정 중 덱을 키운다. 우리는 실시간이라 버튼을 늘릴 수 없으니, **같은 버튼 안의 내용이 원정 중에 바뀌게** 만드는 방향으로 가져온다. (CZN의 세부 수치·명칭은 확인하지 않은 기억 기반 비교)

| 아이디어 | 내용 | 우리 게임에 넣는 방식 |
|---|---|---|
| 원정 중 스킬 변형 ("번뜩임") | 원정 중 카드가 강화·변형되며 덱이 달라지는 맛 | 전투 보상 3택1의 "스킬 강화"를 **이번 원정 한정 변형**으로 확장. 예: ① 도발 → "가시 도발(반사)" / "넓은 도발(범위↑)". 버튼은 그대로, 원정마다 빌드가 달라진다 |
| 덱 압축 = 선택과 포기 | 약한 카드를 빼서 원하는 카드가 자주 나오게 | 변형을 고를 때 "다른 스킬의 쿨타임 +"같은 대가를 붙여 트레이드오프를 만든다 |
| 원정 결과의 영구화 | 잘 만든 런의 일부를 남긴다 | 심연 던전 최고 기록 파티의 변형 1개를 "기억"으로 보존해 다음 원정 시작 시 1회 선택 가능 |
| 지원 캐릭터 | 출전하지 않는 캐릭터도 도움 | 출전 3명 + **지원 1명**: 패시브 1개와 필살기 게이지 보조만. 버튼은 늘지 않고 캐릭터 수집 가치가 오른다 (소울 메달 '어시스트' 안과 연결) |
| 정신력(스트레스) | 오래 싸울수록 쌓이는 부담 | 심연 던전 소모전에 **피로도**: 연속 출전하면 쌓이고 교대로 회복 → 교대 판단에 이유가 생긴다 |

## 7-4. 그로기 역할 분담 (구현됨)

근거 조사: `reports/그로기 역할 분담 설계.md` · 검증 결과: `docs/break_verification.md` (`node tools/break_lab.cjs`)

**원칙: 그로기 게이지는 하나, 게이지를 깎는 "일"을 쪼개고, 탱커는 혼자 할 수 있는 지름길로 남긴다.**

| 규칙 | 내용 |
|---|---|
| 끊기 칸 | 큰 적의 차지·호출 위에 **○○○ 3칸** (작은 적·꽃봉오리 1칸). 2초 안에 칸을 다 채우면 끊김. 못 채운 칸은 1칸당 그로기 17로 바뀜. 화면에는 숫자 없이 칸만 보인다 |
| 같은 직업 중복 | **같은 직업은 한 번만 친다** → 직업을 섞어야 끊긴다 (원딜 2명 = ●● 실패) |
| 흔들림 | 끊기·기절에 성공하면 8초 흔들림: 게이지 회복 0, 그로기 피해 ×1.5. 원딜 관통 사격이 +3초 (최대 12초). 그로기 게이지는 5칸 눈금으로 표시 |
| 회복 | 흔들림이 아닐 때 초당 7, 흔들림이 끝나면 1.5초 뒤 재개 |
| 점감 | 15초 안 반복 기절은 ×0.6 → ×0.3. 그로기마다 게이지 최대치 +15% (최대 1.3배), 그로기 끝나고 3초간 게이지 감소 불가 |
| 필살기 그로기 | 흔들림 밖에서는 절반 (필살기 하나로 기믹을 건너뛰지 못하게) |
| 놓친 대가 | 끊지 못한 차지 3회째부터 격노 스택(+10%씩). 끊지 못한 호출 → 졸개 + 방어 태세 강화. 보스 소프트 인레이지(110~150초 뒤 10초마다 +5%) |

| 직업 | 그로기에서 맡는 일 | 스킬 |
|---|---|---|
| 탱커 | 혼자 끊기 (기절 = 칸 전부) | ② 방패 강타 |
| 근딜 | 끊기 ●● (정면 ●), 큰 적은 등 뒤로 돌아감 | ① 급소 베기 |
| 원딜 | 끊기 ●● + 흔들림 연장 3초 | ① 관통 사격 |
| 매지션 | 범위 끊기 ● (범위 안 모든 적) | ② 유성우 |
| 서포터 | 공명: 대상 아군의 그로기 피해 +30% (5초) | ① 치유 |

**보스 로테이션 (원정마다 무작위, 지도에서 미리 보임)**

| 보스 | 기믹 | 우대 |
|---|---|---|
| 오우거 대족장 | 정면 강차지 | 탱커 |
| 가시덩굴 여왕 | 꽃봉오리 3개가 동시에 호출 (각 1칸). 호출 성공마다 여왕 회복 + 방어 강화 | 매지션 (범위 끊기) |
| 안개 사슴왕 | 정면 그로기 ×0.3, 정면 원거리 피해 ×0.6, 후열을 노림, 2페이즈 기절 면역 | 근딜 (후방) |
| 늪거북 장로 | 게이지 회복 20/초 (HP 50% 이하 절반), 표식(취약)이 걸리면 회복 정지, 기절로 차지가 안 끊김 | 원딜·서포터 |

- 자동 전략 조건 추가: **끊기 타이밍 고려**(다음 차지 전에 쿨이 돌아오면 사용, 파티가 못 끊는 상대면 아끼지 않음), **필살기에 맞게 자동**(부활·회복·그로기 만들기·무방비 수확을 필살기 종류로 판단).
- 서포터 필살기 게이지는 회복량으로도 찬다.

## 7-5. 보스 압박과 레벨 차이 (구현됨)

**원칙: 동레벨이면 탱커(또는 아주 단단한 근딜)가 있어야 버틴다. 장비로 레벨을 올리면 탱커 없이도 되고, 레벨 차가 크면 딜찍누.**

| 규칙 | 내용 |
|---|---|
| 짓누름 | 보스 평타에 맞을 때마다 1겹(최대 5겹, 8초 유지). 1겹당 보스 평타 피해 +40%. 탱커는 효과 85% 감소, 든든함 특성(브란) 60% 감소. 버티는 중(도발·철벽)이면 쌓이지 않음 |
| 위협 | 보스는 가까운 탱커를 먼저 노린다. 안개 사슴왕은 후열을 노리므로 탱커가 도발로 데려와야 함 (도발이 끝나도 3초 더 탱커를 노림) |
| 탱커 AI | 짓누름 2겹 이상 쌓인 동료를 보스가 때리면 도발로 시선을 뺏는다 (차지가 곧 오면 아껴 둠) |
| 덮치기 | 보스가 4초 넘게 대상을 못 따라잡으면 덮쳐 든다 (멀리서 끌기만으로 버티기 불가) |
| 레벨 차이 | 파티 − 던전. 낮으면 레벨당 주는 피해 −2.5%, 받는 피해 +3%. 높으면 레벨당 주는 피해 +3%(최대 3배), 받는 피해 −2.5%(최소 0.3배) |
| 전투 레벨 | 캐릭터 레벨 + 장비 레벨(등급 순서 × 10 + 강화, 6부위 평균). 던전 레벨 = 권장 캐릭터 레벨(1·3·12·22·32·40·50·60·70) + 권장 장비 레벨(권장 등급 × 10 + 5). 캐릭터 10레벨 ≈ 장비 1등급 |
| 서포터 | 평타 사거리 안에 서서 싸운다. 동료가 HP 60% 아래면 그 뒤로 붙는다 (회복은 거리 제한 없음) |

**난이도 단계 재조정** (`tools/equip_balance.cjs --calibrate` → `--calib-merge`, 검증 `--tier-matrix`, 엑셀 `docs/equipment_db.xlsx` 난이도 시트): 단계 배율 = 권장 등급 풀세트 +5강(레벨 차 0)이 장비 없는 기본 던전과 같은 체감 난이도가 되는 적 배율.

| 단계 | 견습 | 숙련 | 정예 | 영웅 | 전설 | 신화 | 고대 | 태초 |
|---|---|---|---|---|---|---|---|---|
| 권장 | UC | C | R | SR | SSR | UR | L | E |
| 던전 Lv (캐릭터 + 장비) | 3+15 | 12+25 | 22+35 | 32+45 | 40+55 | 50+65 | 60+75 | 70+85 |
| 적 배율 (이전) | 1.12 (1.51) | 1.42 (1.60) | 1.67 (1.74) | 2.28 (2.07) | 2.55 (2.52) | 3.28 (3.09) | 4.27 (4.19) | 5.83 (5.10) |

전 단계 공통 결과 (승률, 일반+정예+보스×2): 권장 등급 −1 → 탱커 파티 10~27%, 탱커 없음 0~3% / 권장 등급 → 66~77%, 7~28% / +1 등급 → 91~98%, 66~83% / +2 등급 → 100%, 95~100%.

검증 (`node tools/break_lab.cjs pressure`, 결과는 docs/break_verification.md 0장): 동레벨에서 탱커 파티 약 90%, 브란 파티 30%대, 탱커 없는 파티 0%. 레벨 +20부터 탱커 없는 파티가 이기기 시작하고, +30이면 거의 모든 조합이 이긴다.

## 7-6. 던전 진행: 실시간 다키스트 던전 방식 (구현됨)

`src/js/08b_explore.js`

- **지도**: 방 사이 이동은 지금처럼 고르지만, 방에 무엇이 있는지는 들어가 봐야 안다(?로 표시). 굴의 주인(보스) 방만 보인다. 이동마다 횃불이 줄어든다.
- **방 안**: 파티가 옆으로 걸어간다(멈춤/전진). 길 위에서 만나는 것:

| 만나는 것 | 동작 |
|---|---|
| 적 무리 | 보이는 거리(520px)에 닿으면 그 자리에서 실시간 전투. 전장 폭 = 화면 2배(1920px), 카메라가 파티와 적을 따라감, 화면 밖 유닛은 가장자리 화살표(차지 중이면 붉게 깜빡) |
| 갈림길 | 위쪽 길 / 아래쪽 길. 단서 한 줄(75%는 맞는 단서, 나머지는 "조용하다") |
| 떠돌이 상인 · 수상한 것 · 모닥불 · 고목 | 앞에 멈춰 들어갈지 지나갈지 고른다 |
| 상자 | 지나가며 자동으로 연다 (골드, 가끔 강화석·회복약) |
| 출구 | 방을 나와 지도로 |

- **방 구성** (숨겨진 방 종류 → 처음 / 갈림길 두 갈래 / 끝): 전투 방 = 적 → [상자+적 | 수상한 것], 정예 방 = 적 → [정예 | 상자], 휴식 방 = [적 | 상자] → 모닥불, 이벤트 방 = 수상한 것 → [적 | 상자], 상인 방 = 적 → [상인 | 수상한 것], 고목 방 = 고목 → [적 | 상자], 보스 방 = 적 → [모닥불 | 상인] → 굴의 주인. 방 하나에 전투 0.9번 안팎, 원정 전체 6~7번 + 보스.
- 횃불이 꺼지면 방 안 시야가 어두워지고, 적 무리와 만날 때 정예 습격으로 바뀔 수 있다.
- 다음 단계 후보: 방 안 함정·매복(뒤에서 나타나는 적), 이동 중 횃불 소모, 갈림길 단서를 밝히는 정찰 스킬/아이템.

## 8. 보류 중인 고민: 소울 메달의 최종 역할 (게임 완성 단계에서 다시 결정)

**지금 결정:** 소울 메달 = 직업 특성 스탯 + ①(갑옷)·②(무기) 스킬 위력 강화 (수치형). 필살기 변형은 캐릭터 돌파로 옮겼으므로 메달은 필살기를 건드리지 않는다.

**고민 중인 이유:** 수치만 올리는 메달은 아깝다. 패시브는 이미 갑옷에 있고, 필살기 변형은 캐릭터 돌파가 가져갔다. 메달은 직업 전용이라 직업에 관련된 혜택이어야 하는데, 직업을 가르는 것은 결국 무기 스킬이다.

| 후보 | 내용 | 장점 | 걱정 |
|---|---|---|---|
| A. 수치 강화 (현재) | ①② 스킬 위력·특성 스탯 | 단순, 버튼·규칙 추가 없음 | 개성이 약함 |
| B. 무기 스킬 변형 | 메달이 ② 무기 스킬의 동작을 바꿈 | 직업 전용 = 무기 스킬과 잘 맞음 | 변형 시스템이 필살기 돌파와 겹쳐 복잡 |
| C. 파티 세트 효과 | 같은 계열 메달 수에 따라 파티 전체 효과 | 파티 구성 전략, 직업 간 시너지 | 직업 전용 아이템의 의미가 흐려짐 |
| D. 어시스트 (동료 소환) | 메달에 동료를 박아 두면 가끔 지원 행동 (카오스 제로 나이트메어식) | 수집 요소, 캐릭터 판매와 연결 | 사실상 스킬이 하나 늘어나 조작·화면 부담 |
| E. 아티팩트형 (스탯·스킬 증폭) | 특정 조건 효과 + 스탯 (레전드 오브 아이온/아티팩트류) | 장비 파밍 루프와 잘 맞음 | A와 차이가 작음 |
| F. 전용 메달 가챠 | 캐릭터 전용 메달이 그 캐릭터의 무기 스킬을 변형 (B의 수익화) | 가챠 상품 다양화 | 장비 판매 금지 원칙과 충돌 → 신중 |

결정 시점: 캐릭터·필살기·돌파 구조가 구현되고 실제 플레이로 "빌드에 무엇이 부족한지" 확인된 뒤.
