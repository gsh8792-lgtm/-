# 숲속 원정대 — 장기 게임 설계

> 데모(`dist/forest_expedition.html`)를 넘어 장기 운영 게임으로 가기 위한 설계 문서.
> 구현 현황은 맨 아래 [구현 현황](#구현-현황) 참고.

## 1. 게임의 방향

**한 줄 요약: 높은 난이도를 새로운 빌드로 뚫어 나가는 실시간 3인 파티 전략 RPG.**
방치형은 하지 않는다. 오래 하는 이유는 "더 센 숫자"가 아니라 "아직 못 깬 기믹을 새 빌드로 깨는 것"이다.

### 1-1. 자물쇠와 열쇠 (가챠 운영 원칙)
| 원칙 | 내용 |
|---|---|
| 콘텐츠 = 자물쇠 | 새 시즌·보스는 새 기믹을 낸다 (실드 회복, 분신, 반사막, 시간차 폭발, 매혹 등) |
| 캐릭터 = 열쇠 | 새 캐릭터는 새 해법(동사)을 가져온다 (실드 파괴, 끌어오기, 정화, 반사, 시간 정지, 소환 등) |
| 열쇠는 여러 개 | 같은 자물쇠를 기존 캐릭터 조합으로도 풀 수 있어야 한다. "신캐 없으면 못 깸"은 금지, "신캐로 새 공략법이 열림"은 허용 |
| 스탯 예산 고정 | 신캐의 스탯 총량은 기존 캐릭터와 같다. 차이는 기능으로만 낸다 (파워 인플레 방지) |
| 기믹 무시 금지 | "그로기 무시", "약점 무시" 같은 효과는 넣지 않는다 (스타레일 파워 크립 사례) |
| 리워크 | 오래된 캐릭터는 주기적으로 각성(새 태그 추가)해 다시 쓸 이유를 만든다 |

### 1-2. 캐릭터 = 직업 × 기믹 태그
| 축 | 예시 |
|---|---|
| 직업(역할) | 탱커, 근딜, 원딜, 매지션, 서포터 (+ 추후 소환사, 방해꾼) |
| 기믹 태그 | [끊기] [그로기 특화] [정화] [위치 조작] [실드 파괴] [소환] [반사] … |
| 작전 성향 | 돌격형 / 대형형 / 후퇴형 (작전별 보너스가 다름) |

같은 탱커라도 "끊기 탱커"와 "끌어오기 탱커"는 다른 빌드가 된다. 장비는 직업 공용이라 장비 파밍의 가치가 유지된다.

### 1-3. 수익 구조
| 판매 | 판매하지 않음 |
|---|---|
| 캐릭터 가챠 (천장 있음) | **장비** — 장비는 플레이로 파밍한다. 빌드 연구의 재미를 지킨다 |
| **캐릭터 스킨 + 무기 스킨** | 강화 재료 직판 (주간 한정 패키지 정도만 검토) |
| 시즌 패스 | 스탯을 직접 올리는 상품 |

- **캐릭터를 사는 이유 = 그 캐릭터만의 필살기 풀.** 장비가 ①②를 정하므로 캐릭터의 정체성은 고유 필살기들에 있다 (아래 2-2).
- 중복 획득(돌파)은 필살기를 **강화**하고 **변주**를 연다. 과금 차이 = "더 셈"이 아니라 "선택지가 많음". 예: "3돌파하면 두 번째 필살기의 변주가 열리는데 그게 매력적이다"가 뽑을 이유가 된다.
- 무기 스킨은 외형만 바꾸고, 등급·강화 발광 효과는 스킨 위에도 그대로 보인다.

## 2. 스킬 구조 (확정)

캐릭터당 버튼 3개는 늘리지 않는다. 깊이는 "무엇을 들고 가느냐"로 만든다.

| 버튼 | 결정 요소 | 규칙 |
|---|---|---|
| ① | **갑옷** | 갑옷 종류마다 ① 스킬이 고정. 장비 등급은 같은 스킬의 랭크를 올림 |
| ② | **무기** | 무기 종류마다 ② 스킬이 고정. 직업마다 무기 계열 6종(딜/공략/생존 축) |
| ③ | **캐릭터 고유 필살기 풀** | 캐릭터마다 여러 개(다키스트 던전처럼 많이 배우고 1개 장착). 레벨 10마다 1개 해금, 최대 레벨/10개 (70레벨 = 7개) |
| (패시브) | **갑옷 랜덤 패시브** | 고유 이름 패시브가 랜덤으로 붙고, 패시브 등급은 장비 등급 이하에서 랜덤 |
| (강화) | **소울 메달** | 직업 특성 스탯 + ①(갑옷)·② (무기) 스킬 위력 강화. 메달의 최종 역할은 보류 (8장) |

- 교체는 거점(마을)과 원정 중 캠프에서만. 전투 중에는 작전·자동 전략만 바꾼다.
- 어떤 장비 조합이든 그로기를 깎는 수단이 최소 1개 남도록 스킬 풀을 짠다.

### 2-1. 갑옷 패시브
- **이름은 고정, 등급은 배율.** 같은 패시브는 등급마다 수치만 다르다 (UC 1.0 → C 1.15 → R 1.3 → SR 1.5 → SSR 1.75 → UR 2.0 → L 2.3 → E 2.6).
- 등급이 오를수록 성격이 달라진다: UC~R 수치형 / SR~SSR 조건부 발동형 / UR 이상 트레이드오프·키스톤형.
- 같은 이름 패시브가 겹치면 가장 높은 등급 하나만 적용. 파티 대상 패시브는 파티에서 1개만 적용.
- 관리 수단: 재련(종류 재굴림), 연마(등급 재굴림, 장비 등급 이하), 도감(획득 기록), 잠금.

### 2-2. 캐릭터 필살기와 중복 돌파 (가챠의 핵심)
- 캐릭터마다 고유 필살기 여러 개. 레벨로 해금하고 전투 전에 1개를 고른다.
- **돌파(중복 획득)** 단계마다 필살기가 강화되고, 정해진 단계에서 **변주**가 열린다. 변주는 강화된 별도 선택지라 원본과 바꿔 낄 수 있다.
  - 예: 1돌파 = 첫 필살기 위력 강화 / 2돌파 = 첫 필살기 변주 해금 / 3돌파 = 두 번째 필살기 변주 해금 / … 
- 변주는 수치 변경이 아니라 **동작이 바뀌거나 새 기능이 붙는 것**이어야 한다. 돌파하지 않아도 원본 필살기로 콘텐츠를 깰 수 있어야 한다 (변주 = 다른 공략법, 필수 아님).

| 변형 종류 | 예시 |
|---|---|
| 동작 변화 | 별비 「화살비」 → 「회오리 화살비」: 지정 지점이 아니라 별비 주위를 돌며 3초간 쏟아짐 (근접 방어형) |
| 기능 추가 | 토비 「철벽」 → 「반격 철벽」: 철벽 중 받은 피해의 일부를 그로기 피해로 되돌림 |
| 조건 전환 | 솔담 「대마법」 → 「지연 대마법」: 3초 뒤 발동, 그 순간 무방비인 적에게 3배 |
| 대상 전환 | 보리 「생명의 나무」 → 「이식」: 파티 대신 한 명에게 집중, 그 아군의 다음 필살기 게이지 +50% |
| **잭팟 변주** (높은 돌파 단계) | 단비 「난도질」 → 「천 갈래 칼날」: 6연타가 주변 모든 적으로 튀며, 무방비 적 처치 시 게이지 50% 반환 |

- 잭팟급 변주(높은 돌파 단계)는 무방비 6초 안에 고점을 찍게 해주는 효과가 중심. 단, 무방비 시간 연장·그로기 무시는 금지.
- 무방비 중 피해 증폭은 곱이 아니라 합, 상한 있음 (기본 +50% 위에 최대 +40%).

## 3. 장비 강화

### 3-1. 원칙
강화하면 할수록 **더 높은 난이도의 콘텐츠에 도전**할 수 있게 한다 (데미지 놀이가 아니라 도달 높이).
- 난이도 단계(견습 → 태초)와 심연 던전 층수가 강화의 목표가 된다.
- 장비 파괴 없음 (모바일 정서상 고등급 장비 손실은 좌절이 크다).

### 3-2. 강화 수치 (1차 안)
| 강화 | 성공 확률 | 비고 |
|---|---|---|
| +1 ~ +2 | 100% | |
| +3 / +4 / +5 | 95 / 90 / 85% | **+5: 외형 1단계** |
| +6 / +7 / +8 | 75 / 65 / 55% | |
| +9 / +10 | 45 / 35% | **+10: 외형 2단계** |
| +11 / +12 / +13 | 25 / 18 / 12% | |
| +14 / +15 | 8 / 5% | **+15: 외형 3단계** |

- **실패 보정 (로스트아크식):** 실패할 때마다 이번 단계 확률이 기본 확률의 10%씩 올라가고(최대 2배), **장인의 기운**이 (현재 확률 × 0.465)만큼 쌓인다. 기운 100%면 다음 강화는 확정 성공. 단계가 오르면 보정과 기운은 초기화.
- 실패해도 단계가 내려가지 않는다. 대신 재료는 소모된다.
- 강화 한도는 장비 등급에 묶인다: UC +5, C +7, R +9, SR +11, SSR +13, UR 이상 +15.
- 강화 1단계마다 주 스탯 +6% (+15 = +90%). 추가 옵션·패시브는 강화로 오르지 않는다 (빌드는 옵션·패시브로, 도달 높이는 강화로).
- 재료: 강화석(전투 보상) + 골드. 단계가 오를수록 증가.

### 3-3. 외형
| 요소 | 규칙 |
|---|---|
| 무기 발광 (등급) | 등급이 높을수록 자주·강하게 번쩍인다. UC·C 없음 → R 느린 파랑 → SR 초록 → SSR 보라 → UR 주황 → L 금색 → E 붉은 금색 상시 번쩍임 |
| 무기 발광 (강화) | 강화 단계가 발광의 세기를 키운다. +10부터 불꽃 입자, +15는 잔상까지 |
| 갑옷 외형 (강화) | +5 금색 장식, +10 빛나는 문양, +15 오라와 떠다니는 빛 입자 |
| 스킨 | 스킨 위에도 등급·강화 효과가 겹쳐 보인다 |

## 4. 엔드게임 (방치형 없이 오래 하게)

| 콘텐츠 | 방식 | 오래 하는 이유 |
|---|---|---|
| **심연 던전** (상시) | 무한히 이어지는 층. 아래 4장 | 소모전과 교대 판단, 계속 바뀌는 층 성격 |
| **주간 보스 토벌** | 매주 보스 1종과 기믹 조합이 바뀜. 클리어 시간·계약 점수 랭킹 | 매주 새 공략 연구 |
| **고목의 탑** (시즌 등반) | 시즌마다 리셋되는 고난도 층. 상층은 파티 2~3개 필요, 한 캐릭터는 한 파티에만 | 캐릭터 폭 = 실력, 최상층은 소수만 |
| **원정 일지** (스토리) | 챕터마다 새 자물쇠 기믹을 처음 가르치는 튜토리얼 | 신캐·신기믹 소개 |
| 난이도 계약 | 원정에 조건을 붙여 점수를 올림 (하데스 열기 방식). 예: 차지 범위 +30%, 그로기 회복 2배, 회복약 금지 | 조건 조합마다 다른 빌드 |

PvP는 하지 않는다 (실시간 3인 밸런스·네트워크 비용, 기믹 공략 정체성과 맞지 않음). 대신 **같은 시드의 주간 도전 랭킹**으로 경쟁 욕구를 채운다.

## 5. 심연 던전: 소모전과 교대

층이 끝없이 이어지고, 체력과 사망이 이어지는 **소모전**이다. 핵심 재미는 "다음 층의 성격을 보고 누구를 내보낼지" 고르는 판단.

### 5-1. 규칙
- 원정 시작 시 **예비대**를 꾸린다: 출전 3명 + 대기 최대 5명.
- 체력은 층 사이에 회복되지 않는다. 사망한 캐릭터는 이번 심연 원정에서 **은퇴**(다음 원정에 복귀).
- 대기 중인 캐릭터는 층마다 최대 HP의 15% 회복 (쉬는 캐릭터를 돌리는 이유).
- 층마다 **성격 태그**가 미리 보인다: 예) [차지 다수] [졸개 물량] [회복 저하] [원거리 강화] [어둠: 시야 제한] [보스 층].

### 5-2. 교대 규칙 (층 사이)
| 다음 층 종류 | 교대 가능 인원 |
|---|---|
| 일반 층 | 1명 |
| 정예 층 직후 | 2명 |
| 캠프 층 (5층마다) | 전원 + 식량으로 회복 |
| 위기 층 (랜덤) | 교대 불가, 대신 보상 2배 |

- 이번 층 성격에 맞는 캐릭터를 넣고, 지친 캐릭터를 쉬게 하는 판단이 전략의 중심이 된다.
- 교대 인원 제한 때문에 "만능 3명"보다 "상황별 열쇠를 가진 넓은 로스터"가 유리하다 → 캐릭터 수집 동기와 연결.
- 기록: 도달 층수 + 남은 인원 + 계약 점수로 시즌 랭킹.

## 6. 속성 (나중에 구현, 데이터 자리는 지금 만든다)

**결론: 구현은 엔드게임 단계에서, 데이터 칸은 지금 미리 만든다.** 스킬과 적이 많아진 뒤에 속성을 붙이면 전부 다시 손봐야 하기 때문이다.

- 속성 5종 안: 불 · 물 · 바람 · 대지 · 빛/어둠.
- **약점은 피해량이 아니라 그로기 게이지를 더 크게 깎는다** (스타레일식). 속성이 딜찍누 수단이 아니라 기믹 공략 수단이 되게 한다.
- 요일 던전: 요일마다 속성이 바뀌는 던전에서 그 속성의 보석·강화 재료를 얻는다.
- 신캐의 속성이 새 자물쇠(속성 보호막 보스 등)의 열쇠가 된다.

## 7. 마을 (거점)

| 시설 | 기능 |
|---|---|
| 원정 게시판 (포털) | 던전 입장, 난이도 단계 선택 (클리어하면 다음 단계 해금) |
| 대장간 | 장비 강화 |
| 보관함 | 인벤토리, 장비 장착·비교 |
| 길잡이 | 도움말 |
| (예정) 심연의 문 · 토벌 게시판 · 고목의 탑 | 엔드게임 입구 |

## 8. 보류 중인 고민: 소울 메달의 최종 역할 (게임 완성 단계에서 다시 결정)

**지금 결정:** 소울 메달 = 직업 특성 스탯 + ①(갑옷)·②(무기) 스킬 위력 강화 (수치형). 필살기 변형은 캐릭터 돌파로 옮겼으므로 메달은 필살기를 건드리지 않는다.

**고민 중인 이유:** 수치만 올리는 메달은 아깝다. 패시브는 이미 갑옷에 있고, 필살기 변형은 캐릭터 돌파가 가져갔다. 메달은 직업 전용이라 직업에 관련된 혜택이어야 하는데, 직업을 가르는 것은 결국 무기 스킬이다.

| 후보 | 내용 | 장점 | 걱정 |
|---|---|---|---|
| A. 수치 강화 (현재) | ①② 스킬 위력·특성 스탯 | 단순, 버튼·규칙 추가 없음 | 개성이 약함 |
| B. 무기 스킬 변형 | 메달이 ② 무기 스킬의 동작을 바꿈 | 직업 전용 = 무기 스킬과 잘 맞음 | 변형 시스템이 필살기 돌파와 겹쳐 복잡 |
| C. 파티 세트 효과 | 같은 계열 메달 수에 따라 파티 전체 효과 | 파티 구성 전략, 직업 간 시너지 | 직업 전용 아이템의 의미가 흐려짐 |
| D. 어시스트 (동료 소환) | 메달에 동료를 박아 두면 가끔 지원 행동 (카오스 제로 나이트메어식) | 수집 요소, 캐릭터 판매와 연결 | 사실상 스킬이 하나 늘어나 조작·화면 부담 |
| E. 아티팩트형 (스탯·스킬 증폭) | 특정 조건 효과 + 스탯 (레전드 오브 아이온/아티팩트류) | 장비 파밍 루프와 잘 맞음 | A와 차이가 작음 |
| F. 전용 메달 가챠 | 캐릭터 전용 메달이 그 캐릭터의 무기 스킬을 변형 (B의 수익화) | 가챠 상품 다양화 | 장비 판매 금지 원칙과 충돌 → 신중 |

결정 시점: 캐릭터·필살기·돌파 구조가 구현되고 실제 플레이로 "빌드에 무엇이 부족한지" 확인된 뒤.
